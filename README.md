# desk

- **`index.html`** — site root: a passcode-gated vision board, 3x3 on desktop and a full-width stack on mobile. Images live in [`vision/`](vision/README.md). The passcode check runs in the browser, so it deters casual visitors but is not real security — keep nothing sensitive here.
- **`dialer/`** — Dial Sheet, a single-file CRM and click-to-call sheet for outbound calling. Served at `/dialer/` when the repo root is published as a static site. See [`dialer/README.md`](dialer/README.md).
- **`core/`** — packages and scripts.
